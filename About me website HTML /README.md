## About Me website Project ##

### Overview ###
A multi-page personal website created for a university Software Development module. It introduces me, presents information about my qualifications and interests in cybersecurity, and includes pages demonstrating HTML, CSS and JavaScript.
### Pages and content ###
- Home (index.html) — personal introduction and links.
- Qualifications (qualifications.html) — a qualifications table and information about relevant study.
- Interests (interests.html) — an introduction to cybersecurity and practical advice for protecting personal data.
- Demos (demos.html) — demonstration pages for web technologies, including CSS and JavaScript.
### Technologies ###
- HTML for page structure and content.
- CSS for styling and layout, including shared base styles.
- JavaScript for interactive demonstration features.
- Browser developer tools and Lighthouse for checking the site during development.
### Running locally ###
1. Download or clone the project.
2. Open the public folder.
3. Open index.html in a web browser. For a more consistent local development experience, use Visual Studio Code with a local server extension.
4. Navigate between the Home, Qualifications, Interests and Demos pages using the site menu.
### What I practised ###
- Organising a small multi-page website.
- Linking shared stylesheets and JavaScript files.
- Using semantic page structure, navigation links, images and alternative text.
- Adjusting layout and checking the site at different viewport sizes.
- Testing the website with Lighthouse and making layout adjustments.
